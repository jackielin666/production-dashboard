# production-dashboard
不良率/報廢率/金撿報廢率統計

## 登入（簡易密碼頁）

首頁、月報（`reports/`）與月報索引都要先登入，由 `auth.js` 負責。

| 規則 | 說明 |
|---|---|
| 登入範圍 | 同一個分頁內登入一次，首頁與月報通用 |
| 重新登入 | 關閉分頁或瀏覽器後需重新登入 |
| 閒置登出 | 閒置 15 分鐘自動登出；第 14 分鐘跳出提醒（滑鼠、鍵盤、觸控、捲動都算使用中） |
| 搜尋引擎 | 所有頁面都有 `noindex, nofollow`，不被收錄 |

**限制**：這是「門簾」不是「鎖」。靜態網站沒有後端，`data/latest.xlsx`、`reports/*.json`
知道網址仍可直接下載；帳號清單（雜湊值）也在公開的 `auth.js` 內。

### 帳號維護（由系統管理員 Jackie 負責）

目前帳號：`adm0` Jackie（系統管理員）、`adm1` Tommy、`140` 廠長。
「系統管理員」在畫面上沒有額外功能，只代表負責新增、刪除帳號與重設密碼。

1. 產生雜湊值（密碼明碼**不要**寫進任何檔案）：
   ```bash
   python3 tools/auth_hash.py 帳號 新密碼
   ```
2. 把輸出那一行貼到 `auth.js` 的 `ACCOUNTS`（新增）、或替換該帳號的 `hash`（重設密碼）；
   刪除帳號就刪掉那一行。
3. 提交並推上 main，約 1–10 分鐘生效（GitHub Pages 部署＋瀏覽器快取）。
